**💻🔏Asp.Net Identity Notları🔏💻**

1-) ASP.NET Core Identity Nedir ? Ne işe yarar ? 
ASP.NET Core Identity, ASP.NET Core uygulamalarında kullanıcı kimlik doğrulaması ve yetkilendirme işlemlerini yönetmek için kullanılan bir kütüphanedir. Bu kütüphane, kullanıcıların kaydolmasını, giriş yapmasını, şifrelerini sıfırlamasını ve diğer kimlik doğrulama ve yetkilendirme işlemlerini kolayca yönetmenize olanak tanır. Ayrıca, rol tabanlı erişim kontrolü gibi gelişmiş yetkilendirme özellikleri de sunar.
